# [Compose Manager Plus](https://github.com/mstrhakr/compose_plugin)

This directory contains the configuration files of the different docker compose stacks created with the unRAID plugin [Compose Manager Plus](https://github.com/mstrhakr/compose_plugin).

The [`get_new`](./get_new) script is only used for me to copy the new files from their location on the unRAID-server in `/boot/config/plugins/compose.manager/projects` into this repository &mdash; for persistence.
